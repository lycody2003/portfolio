## Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lycody2003/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal. The development server is configured to use port `3002`.

### Generate a Static Site

To generate the production-ready static files:

```bash
npm run generate
```

The generated website is available in:

```text
.output/public/
```

## Deployment

This portfolio is deployed using **GitHub Pages** and can be built and published through GitHub Actions.

[https://lycody2003.github.io/portfolio/](https://lycody2003.github.io/portfolio/)
